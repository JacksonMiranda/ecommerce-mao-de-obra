## Reportando uma Vulnerabilidade

A segurança do projeto é levada a sério. Se você descobrir uma vulnerabilidade de segurança, 
por favor, siga estas diretrizes:

### Como Reportar

1. **NÃO** abra uma issue pública sobre a vulnerabilidade
2. Envie um email para jackson.j.m@hotmail.com com os detalhes
3. Inclua no assunto: "SECURITY: [Breve descrição]"

### Informações a Incluir

- Descrição detalhada da vulnerabilidade
- Passos para reproduzir o problema
- Possível impacto da vulnerabilidade
- Sugestões para correção (se houver)
- Suas informações de contato

### Processo de Resposta

- **Confirmação**: Confirmaremos o recebimento em até 48 horas
- **Investigação**: Investigaremos o problema em até 5 dias úteis
- **Correção**: Trabalharemos para corrigir a vulnerabilidade
- **Divulgação**: Coordenaremos com você sobre a divulgação pública

### Reconhecimento

Reconhecemos e agradecemos pesquisadores de segurança responsáveis que reportam vulnerabilidades. Com sua permissão, incluiremos seu nome em nossos agradecimentos.

## Reporting a Vulnerability

Project security is taken seriously. If you discover a security vulnerability, 
please follow these guidelines:

### How to Report

1. **DO NOT** open a public issue about the vulnerability
2. Send an email to jackson.j.m@hotmail.com with the details
3. Include in the subject: "SECURITY: [Brief description]"

### Information to Include

- Detailed description of the vulnerability
- Steps to reproduce the issue
- Possible impact of the vulnerability
- Suggestions for fixing (if any)
- Your contact information

### Response Process

- **Acknowledgment**: We'll confirm receipt within 48 hours
- **Investigation**: We'll investigate the issue within 5 business days
- **Fix**: We'll work to fix the vulnerability
- **Disclosure**: We'll coordinate with you about public disclosure

### Recognition

We acknowledge and thank responsible security researchers who report vulnerabilities. With your permission, we'll include your name in our acknowledgments.
