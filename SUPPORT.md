## 🇧🇷 Como Obter Suporte

### Antes de Pedir Ajuda

1. Consulte a [documentação](README.md)
2. Verifique as [issues existentes](https://github.com/JacksonMiranda/ecommerce-mao-de-obra/issues)
3. Leia o [guia de contribuição](CONTRIBUTING.md)

### Tipos de Suporte Disponíveis

#### 🐛 Bugs e Problemas Técnicos
- Abra uma [nova issue](https://github.com/JacksonMiranda/ecommerce-mao-de-obra/issues/new)
- Use o template apropriado
- Inclua informações detalhadas sobre o problema

#### 💡 Solicitações de Funcionalidades
- Abra uma [feature request](https://github.com/JacksonMiranda/ecommerce-mao-de-obra/issues/new)
- Descreva o caso de uso
- Explique como isso beneficiaria outros usuários

#### ❓ Dúvidas Gerais
- Use as [Discussions](https://github.com/JacksonMiranda/ecommerce-mao-de-obra/discussions)
- Entre em contato: jackson.j.m@hotmail.com

### Informações Úteis para Incluir

- Versão do projeto
- Navegador e versão
- Sistema operacional
- Passos para reproduzir o problema
- Mensagens de erro (se houver)
- Screenshots (se aplicável)

### Tempo de Resposta

- Issues críticas: 24-48 horas
- Issues normais: 2-5 dias úteis
- Feature requests: 1-2 semanas
- Dúvidas gerais: 2-7 dias

## How to Get Support

### Before Asking for Help

1. Check the [documentation](README.md)
2. Look through [existing issues](https://github.com/JacksonMiranda/ecommerce-mao-de-obra/issues)
3. Read the [contributing guide](CONTRIBUTING.md)

### Available Support Types

#### 🐛 Bugs and Technical Issues
- Open a [new issue](https://github.com/JacksonMiranda/ecommerce-mao-de-obra/issues/new)
- Use the appropriate template
- Include detailed information about the problem

#### 💡 Feature Requests
- Open a [feature request](https://github.com/JacksonMiranda/ecommerce-mao-de-obra/issues/new)
- Describe the use case
- Explain how it would benefit other users

#### ❓ General Questions
- Use [Discussions](https://github.com/JacksonMiranda/ecommerce-mao-de-obra/discussions)
- Contact: jackson.j.m@hotmail.com

### Useful Information to Include

- Project version
- Browser and version
- Operating system
- Steps to reproduce the issue
- Error messages (if any)
- Screenshots (if applicable)

### Response Time

- Critical issues: 24-48 hours
- Regular issues: 2-5 business days
- Feature requests: 1-2 weeks
- General questions: 2-7 days
